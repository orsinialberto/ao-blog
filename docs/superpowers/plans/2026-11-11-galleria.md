# Galleria fotografica — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the masonry `/galleria` with hand-drawn film rolls (index), a serpentine film-strip album page per travel, and a swinging polaroid clothesline section on the homepage.

**Architecture:** Albums are derived from the existing `gallery` frontmatter (one album per travel). All motion and hit-testing logic that can be pure lives in two dependency-free modules (`galleryLogic.ts`, `clotheslineGeometry.ts`) tested with Node's built-in test runner; React client components only wire that logic to DOM events and CSS. Drawing measurements are constants in `src/config/galleryDrawings.ts`.

**Tech Stack:** Next.js 16 static export, React 19, TypeScript, Tailwind 4 + plain CSS in `globals.css`, Cloudinary URLs, `node --test` (no new dependencies).

**Spec:** `docs/superpowers/specs/2026-11-11-galleria-design.md` (Italian). Read it first; the prototypes it lists in `.superpowers/brainstorm/94853-1794428005/content/` show the approved look and motion.

## Global Constraints

- Static export, `trailingSlash: true`; every `[locale]/.../[slug]/page.tsx` exports `generateStaticParams` over all locales × slugs.
- Every UI string in both `src/i18n/messages/it.json` and `en.json`, typed in `src/i18n/types.ts`.
- Cloudinary URLs via `optimizeCloudinaryUrl()`: thumbnails `width: 400`, lightbox keeps `Lightbox`'s own 1920.
- No new npm dependencies. Fail fast and loudly (throw at build with file + field named).
- `prefers-reduced-motion: reduce` → no swinging, no auto/hover ribbon motion, no drop-in; rolls shown open, photos shown developed.
- Album page header: only travel title (hand font, `WigglyText` + `HandUnderline`, i.e. `SectionHeader`) and year. Nothing else.
- Desktop: 5 photos per strip; mobile (`< 768px`, Tailwind `md`): 3 per strip.
- Drawing coordinates are measured on pixels, never eyeballed (spec "Misure dei disegni").
- Pure modules (`*.ts` with tests) import nothing (Node runs them with type stripping, no path aliases, no extensionless imports).

## Review Focus

- A travel with fewer photos than a strip (1–4) → one strip, trailing empty frames, ribbon still loops, no photo shown twice. Test in Task 1.
- `?foto=` with `0`, `abc`, `2.5`, empty, or larger than the album → ignored, no lightbox, no crash. Test in Task 1.
- Fewer than six travels with a gallery → homepage shows that many photos; remaining polaroids stay empty drawings. Test in Task 1.
- A travel with `gallery` but no `shortTitle` (in either language file) → build fails naming the file. Test in Task 1 (`requireShortTitle`), wired in Task 2.
- Pointer on the paper margin of a strip, or leaving the strip mid-motion → ribbon stops. Test in Task 1 (`isOnFilmBand`); `pointerleave` wiring in Task 6.

- Produces (all exported from `src/lib/galleryLogic.ts`):

  - `stripCount(photoCount: number, perStrip: number): number` — `ceil`, `0` for no photos.
  - `slotPhoto(slot: number, photoCount: number, perStrip: number): number | null` — wraps `slot` modulo the ribbon length `stripCount * perStrip` (also negative slots); returns the photo index, or `null` for an empty frame.
  - `frameSlot(offset: number, row: number, k: number, perStrip: number): number` — unwrapped slot shown in frame `k` (0…`perStrip`, i.e. `perStrip + 1` frames per row) of `row`. `base = Math.floor(offset)`; even rows `base + row*perStrip + k`; odd rows `base + row*perStrip + perStrip - k`.
  - `trackShift(offset: number, row: number): number` — horizontal track shift in frames: even rows `-frac`, odd rows `frac - 1` (`frac = offset - Math.floor(offset)`).

  - `parsePhotoParam(value: string | null, photoCount: number): number | null` — 1-based positive integer string within range → 0-based index; anything else `null`.

  - `requireShortTitle(value: unknown, hasGallery: boolean, fileName: string): string | undefined` — trimmed string if non-empty; if empty and `hasGallery`, throws `Error("Missing shortTitle in " + fileName + " (required when gallery is set)")`; otherwise `undefined`.

  - `FILM_TILE: { src: string; aspect: string; tiles: { size: string; position: string }[]; window: { left: number; top: number; width: number; height: number }; band: { top: number; bottom: number } }` — placeholder values from the prototype: aspect `"578 / 737"`, tiles `[{ size: "476.2% 208.3%", position: "36.2% 50%" }, { size: "507.6% 208.3%", position: "61.8% 50%" }]` (alternate by slot parity), window `{ left: 4.5, top: 22.1, width: 92, height: 56.2 }`, band `{ top: 0.073, bottom: 0.937 }`.
  - `CLOTHESLINE: ClotheslineDrawing` (type from `clotheslineGeometry.ts`) with the spec's measured table (rope points, ±11 half band, six polaroids with body, pegs, pivot x, window corners, peg holes as rectangles), halved for the 1200px file; plus per-polaroid `amp` (deg) and `dur` (s): 2.2/3.4, 1.8/3.9, 0.6/4.6, 2/3.6, 2/4.1, 0.8/3.2.
- Produces (`src/lib/clotheslineGeometry.ts`, imports nothing; the config imports its types with `import type`):
  - `type Pt = [number, number]`
  - `interface Polaroid { body: [number, number, number, number]; pegs: { x0: number; x1: number; top: number }[]; pivotX: number; window: [Pt, Pt, Pt, Pt]; pegHoles: [number, number, number, number][]; amp: number; dur: number }`
  - `interface ClotheslineDrawing { src: string; width: number; height: number; rope: Pt[]; ropeHalf: number; polaroids: Polaroid[] }`
  - `ropeY(rope: Pt[], x: number): number` — linear interpolation, clamped to the end points.
  - `ropeBandClipPath(d: ClotheslineDrawing): string` — CSS `polygon(...)` in % (2 decimals), rope ± `ropeHalf`, sampled every 12 drawing px.
  - `bodyClipPath(d: ClotheslineDrawing, p: Polaroid): string` — area from 8px outside `body` x range, top edge following `ropeY + ropeHalf`, down to `body` bottom + 12.
  - `pegClipPath(d: ClotheslineDrawing, peg: Polaroid["pegs"][number]): string` — from `peg.top` down to `ropeY + ropeHalf`.
  - `pivot(d: ClotheslineDrawing, p: Polaroid): { x: string; y: string }` — `pivotX` and `ropeY(pivotX)` as `%`.
  - `windowMask(p: Polaroid): { box: { left: number; top: number; width: number; height: number }; svg: string }` — `box` is the window's bounding box in drawing px; `svg` is a `viewBox="0 0 w h" preserveAspectRatio="none"` path with `fill-rule="evenodd"`: the window quad, minus each peg hole rect, all relative to `box`.
